# הגדרה
תהינה $\left\{ a_{n} \right\},\left\{ b_{n} \right\}$ [[תואר/סדרה\|סדרות]] כך שלכל $n$ מתקיים.
$$
a_{n} \leq a_{n+1} \leq b_{n+1}\leq b_{n}
$$
ובנוסף
$$
\lim_{ n \to \infty } b_{n}-a_{n} =0
$$
אזי
$$
\lim_{ n \to \infty } a_{n}=\lim_{ n \to \infty } b_{n}
$$
# הוכחה
נשים לב ראשית כי $a:=\lim_{ n \to \infty }a_{n}$ וגם $b:=\lim_{ n \to \infty }b_{n}$ קיימים. מדוע?
כיידוע כי $a_{n}$ מונוטונית עולה חלש וחסומה מלעיל מ$b_{1}$ ובאותו אופן $b_{n}$ מונוטונית יורדת חלש וחסומה 
נותר להראות כי $a=b$
$$
\begin{gather}
b=\lim_{ n \to \infty } b_{n} \\
=\lim_{ n \to \infty } \left( b_{n}-a_{n}+a_{n} \right) \\
=\lim_{ n \to \infty } \left( (b_{n}-a_{n})+a_{n} \right) \\
=\lim_{ n \to \infty } \left( b_{n}-a_{n} \right) +\lim_{ n \to \infty } a_{n} \\
=0+a=a
\end{gather}
$$

# גרסה אחרת ושקולה
תהא $\left[ a_{n},b_{n} \right]$ סדרה של קטעים סגורים כך שאורכיהם שואפים ל$0$ ו$\left[ a_{n+1},b_{n+1} \right]\subseteq \left[ a_{n},b_{n} \right]$
אזי קיימת נקודה אחת בודדת $x$ שייכת לכל הקטעים, כלומר: 
$$
\bigcap\limits_{n=1}^{\infty}\left[ a_{n},b_{n} \right] =\left\{ x \right\} 
$$
# הוכחה לגרסה האחרת
נגדיר שתי סדרות, $\left\{ a_{n} \right\},\left\{ b_{n} \right\}$ ונשים לב שמתקיים
$$
a_{n}\leq a_{n+1} \leq b_{n+1}\leq b_{n}
$$
וכמו כן $\lim_{ n \to \infty }\left( b_{n}-a_{n} \right)=0$ (אורך הקטע ה$n$ -י)
לכן קיים גבול משותף $x:=\lim_{ n \to \infty }a_{n}=\lim_{ n \to \infty }b_{n}$
צריך להראות ש$x$ היא הנקודת היחידה המשותפת לכל הקטעים
מדוע $x$ משותפת לכל הקטעים?
$a_{n}\leq x\leq b_{n} \iff x \in \left[ a_{n},b_{n} \right]$, $x$ הוא הגבול של $\left\{ b_{n} \right\}$ שהוא מונוטונית יורדת חלש ולכן $\forall n~x \leq b_{n}$ ובאותו אופן, $x$ הוא הגבול של $\left\{ b_{n} \right\}$ שהיא מונוטונית עולה חלש ולכן $\forall n~x \geq a_{n}$
